## Domain Summary
This frontend supports a generic admin and account-management platform, with authentication flows, user lifecycle management, and a simple item catalog. The core models revolve around login/signup/reset-password, public and private user records with admin flags, and item records that have owners, titles, descriptions, and timestamps.
