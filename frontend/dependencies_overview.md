# Dependencies Overview

- **Package management**: Use `bun` as the package manager for this codebase.
- **@hookform/resolvers**: Purpose: Validation resolvers for React Hook Form that integrate external schema validators like Yup, Zod, Joi, Vest, and Ajv. In TypeScript, many resolvers can infer the form output type from the schema.
- **@tailwindcss/vite**: Purpose: Official Tailwind CSS plugin for Vite. It’s used to integrate Tailwind into Vite projects by adding the plugin in `vite.config.ts` and then using Tailwind utility classes in your app. Source: https://tailwindcss.com/docs/installation/using-vite
- **@tanstack/react-query**: Purpose: React bindings for TanStack Query, a library for fetching, caching, synchronizing, and updating server state in React apps. It provides hooks and utilities like useQuery, useMutation, QueryClient, and QueryClientProvider, with strong TypeScript support.
- **@tanstack/react-query-devtools**: Purpose: React Query devtools for React apps that visualize and inspect queries, mutations, and cache/runtime state to help debugging. Official docs: https://tanstack.com/query/latest/docs/framework/react/devtools
- **@tanstack/react-router**: Purpose: A type-safe router for React applications, with nested routing, inferred TypeScript support, first-class search params, loaders, and file-based routing. Official docs: https://tanstack.com/router/router/docs
- **@tanstack/react-router-devtools**: Purpose: A separate TanStack Router package that adds React devtools for inspecting and debugging router state. It supports embedded, fixed, and floating panel modes, and can also be enabled in production with `TanStackRouterDevtoolsInProd`. Source: https://tanstack.com/router/latest/docs/devtools
- **@tanstack/react-table**: Purpose: React adapter for TanStack Table’s core table logic. It manages table state the React way and provides types plus rendering helpers for cells, headers, and footers.
- **axios**: Purpose: Promise-based HTTP client for the browser and Node.js. It provides a simple API for making requests, with support for request configuration and response handling.
- **class-variance-authority**: Purpose: TypeScript utility for building class-based component variants in a type-safe way. It helps map props to class strings and provides `VariantProps` to extract variant types.
- **clsx**: Purpose: A tiny utility for constructing `className` strings conditionally. It accepts strings, objects, arrays, booleans, and other mixed inputs, discarding falsey values.
- **form-data**: Purpose: Creates readable multipart/form-data streams in Node.js, letting you submit forms and file uploads to web applications. The library is also compatible with TypeScript via its type definitions.
- **lucide-react**: Purpose: Lucide provides a React component library for using icons in your applications. Each icon is a standalone component that renders an optimized inline SVG, with full TypeScript support.
- **next-themes**: Purpose: A theming utility for React/Next.js that provides ThemeProvider and useTheme to manage light, dark, and system themes. It persists the user’s choice, syncs across tabs, and avoids flash on load.
- **Radix UI React Primitives**: Purpose: An open-source, low-level React UI component library for building high-quality, accessible design systems and web apps. Components are unstyled, fully typed, and designed for incremental adoption with strong focus on accessibility and customization.
- **react**: Purpose: React is a JavaScript library for rendering user interfaces, built around reusable, nestable components. It provides React features such as Hooks, Components, and APIs for defining UI behavior. Sources: https://react.dev/learn/describing-the-ui , https://react.dev/reference/react
- **react-dom**: Purpose: React DOM provides the web-specific APIs for React apps running in the browser DOM environment. It includes client rendering and hydration APIs, plus DOM utilities such as portals and synchronous updates.
- **react-error-boundary**: Purpose: Reusable React error boundary component for catching render-time errors in a subtree and showing a fallback UI. Supports all React renderers, including React DOM and React Native.
- **react-hook-form**: Purpose: React Hook Form is a React and React Native library for form state management and validation. The official docs emphasize performance, native HTML validation, and TypeScript support. Source: https://github.com/react-hook-form/react-hook-form
- **react-icons**: Purpose: React icon library for adding popular SVG icon sets to React apps. It uses ES6 imports so you can import only the icons you need, and it includes native TypeScript support (no separate @types package required).
- **sonner**: Purpose: A toast component for React that exposes a `<Toaster />` host and `toast()` helpers for displaying notifications in TypeScript apps. Source: https://sonner.emilkowal.ski/getting-started
- **tailwind-merge**: Purpose: Utility function to efficiently merge Tailwind CSS classes in JS without style conflicts. It is fully typed and intended for JavaScript/TypeScript projects.
- **tailwindcss**: Purpose: A utility-first CSS framework for building custom designs. It scans your HTML, JavaScript components, and templates for class names, generates the needed styles, and writes them to a static CSS file with zero runtime.
- **zod**: Purpose: TypeScript-first schema validation library with static type inference. It lets you define schemas to validate data at runtime and derive TypeScript types from them.
