# Dependencies Overview

This file is the source-of-truth for all frontend runtime and build-time dependencies used in this project.
**Package manager:** npm | **Primary language:** TypeScript

---

## Dependency Catalog

| Name | Purpose | Usage |
|---|---|---|
| `@hookform/resolvers` | A collection of validation resolvers for React Hook Form that enables seamless integration with popular validation libraries such as Yup, Zod, Joi, Vest, Superstruct, Class Validator, and many more. It allows you to use any external validation library — or custom logic — to validate your forms. | Provides adapter functions (resolvers) that act as a bridge between React Hook Form and your chosen validation library, implementing a standardized interface while handling library-specific validation logic. Pass the resolver (e.g., `zodResolver(schema)`) into React Hook Form's `useForm` hook via the `resolver` option to enable schema-based form validation with full TypeScript type inference. |
| `@tailwindcss/vite` | A first-party Vite plugin for integrating Tailwind CSS (v4+) directly into the Vite build pipeline. It is the most seamless way to use Tailwind CSS with Vite-based frameworks like React Router, SvelteKit, Nuxt, Laravel, and SolidJS. | Hooks into Vite's build and dev-server lifecycle to automatically scan source files, generate utility-first CSS, and apply optimizations such as Lightning CSS minification. Replaces the older PostCSS-based setup, offering improved performance, HMR support, and zero-config CSS generation out of the box. |
| `@tanstack/react-query` | TanStack Query (formerly React Query) is often described as the missing data-fetching library for web applications — it makes fetching, caching, synchronizing, and updating server state a breeze. | Provides powerful hooks like `useQuery` and `useMutation` for managing asynchronous server state, with built-in support for caching, background refetching, pagination, and infinite loading. Ships with first-class TypeScript support, dedicated DevTools, and fine-grained configuration options. |
| `@tanstack/react-query-devtools` | Developer tools to interact with and visualize the TanStack React Query cache. Provides an in-app panel that helps developers inspect, debug, and manage server-state during development. | Ships two components — `ReactQueryDevtools` (a floating overlay) and `ReactQueryDevtoolsPanel` (an embeddable panel) — that display query status, cache contents, and allow manual query invalidation in real time. Renders only in development environments by default, keeping production builds unaffected. |
| `@tanstack/react-router` | A powerful, fully type-safe router for building client-side and full-stack React applications, with first-class search-param state management and seamless integration with the React ecosystem. | Provides fully type-safe APIs for defining nested routes, route parameters, and loaders, enabling end-to-end TypeScript safety across navigation. Also offers advanced URL search-parameter management with a powerful parser/serializer for handling complex state structures directly in the URL. |
| `@tanstack/react-router-devtools` | A dedicated developer tooling package for TanStack Router that helps visualize the inner workings of your router setup, providing deep insight into routes, navigation state, and cache. | Exports the `TanStackRouterDevtools` component, which renders a floating, interactive devtools panel in your React application during development to inspect route structure, matched routes, and loader data. Also exports `TanStackRouterDevtoolsPanel` for embedding the devtools inline, with support for lazy-loading or excluding it in production builds. |
| `@tanstack/react-table` | A headless UI adapter for building powerful tables and datagrids in React, built on top of the framework-agnostic TanStack Table core. Provides the logic, state management, and types needed to construct fully customizable table components without enforcing any markup or styles. | Exposes the `useReactTable` hook which manages table state the "React way," along with types and rendering implementations for cells, headers, and rows. Core features include sorting, filtering, pagination, row selection, column grouping, and virtualization support — all via a composable, headless API. |
| `axios` | A promise-based HTTP client for Node.js and the browser. Uses the native Node.js `http` module on the server side and XMLHttpRequest on the client. | Supports automatic request/response data transformation, interceptors to add custom logic before requests or responses are handled, and built-in request cancellation mechanisms. Provides a simple, consistent API for making HTTP requests (GET, POST, PUT, DELETE, etc.) with full TypeScript type support via bundled type definitions. |
| `class-variance-authority` | A TypeScript utility library for building type-safe UI component variants by managing CSS class name composition. Eliminates the pain of manually matching classes to props and adding types when working with CSS-in-TS approaches. | Provides a `cva` function to define base styles and structured variant configurations (including compound and default variants) with full TypeScript type inference. Integrates seamlessly with utility-first frameworks like Tailwind CSS, generating the correct class names at runtime based on the props passed to a component. |
| `clsx` | A tiny (239B) utility for constructing `className` strings conditionally. Serves as a faster and smaller drop-in replacement for the `classnames` module. | Accepts any number of arguments — including strings, objects, arrays, and booleans — and merges them into a single, space-separated class name string, filtering out falsy values. Commonly used in TypeScript/React projects to apply CSS classes conditionally in a concise and type-safe manner. |
| `form-data` | A library to create readable "multipart/form-data" streams. Can be used to submit forms and file uploads to other web applications. | API is inspired by the XMLHttpRequest-2 FormData interface, allowing developers to append fields, files, and readable streams to a form payload with ease. Integrates with HTTP client libraries (e.g., axios, node-fetch) to send multipart requests, including file uploads, to remote endpoints. |
| `lucide-react` | React components for Lucide icons that integrate seamlessly into React applications. Each icon is a fully-typed React component that renders as an optimized inline SVG. | Allows importing any Lucide icon as a React component with full TypeScript support, enabling props-based customization of size, color, and stroke width. Supports excellent tree-shaking so only the icons you use are included in your final bundle, keeping applications lean and performant. |
| `next-themes` | An abstraction for themes in your Next.js/React app, enabling perfect dark mode in 2 lines of code with support for system preferences and custom themes without flashing. | Provides a `ThemeProvider` component to wrap your application, enabling seamless theme switching (e.g., light, dark, system) with no flash of unstyled content. The `useTheme` hook gives components direct access to the current theme state and a setter to programmatically switch themes at runtime. |
| `Radix UI React Primitives` | An open-source, unstyled, and accessible low-level UI component library for building high-quality design systems and web applications in React/TypeScript. Provides headless primitives — including Avatar, Checkbox, Dialog, Dropdown Menu, Label, Radio Group, Scroll Area, Select, Separator, Slot, Tabs, and Tooltip — each with full WAI-ARIA compliance. | Each package (e.g. `@radix-ui/react-dialog`, `@radix-ui/react-tabs`) ships as an independently installable, fully typed TypeScript primitive that exposes composable sub-components (Root, Trigger, Content, etc.) with zero default styles, giving teams complete control over visual design. Handles all complex accessibility concerns — keyboard navigation, focus management, ARIA attributes, and screen-reader announcements. |
| `react` | A JavaScript library for building user interfaces, enabling developers to create reusable UI components that manage their own logic and appearance. | Uses a component-based architecture where UIs are composed of small, reusable pieces, each defined as a JavaScript/TypeScript function returning markup. Provides powerful primitives like `useState` and `useEffect`, with full TypeScript support for type-safe component props, hooks, and JSX. |
| `react-dom` | The entry point to the DOM and server renderers for React. Provides DOM-specific methods that can be used at the top level of your app to mount and manage React component trees in the browser. | Exposes core APIs such as `createRoot` and `hydrateRoot` for rendering React components into DOM nodes, along with utilities like `flushSync` for synchronous state updates. Also includes the `react-dom/server` sub-package providing server-side rendering APIs (e.g., `renderToString`, `renderToPipeableStream`). |
| `react-error-boundary` | A simple, reusable React error boundary component that catches JavaScript errors anywhere in a child component tree and displays a fallback UI instead of crashing the whole app. Built on top of React's native error boundary API. | Provides the `ErrorBoundary` component along with a `withErrorBoundary` higher-order component and a `useErrorBoundary` hook, enabling both declarative and programmatic error handling. Features include customizable fallback UI rendering, error reset callbacks (`onReset`, `onError`), and the ability to reset boundaries imperatively. |
| `react-hook-form` | A performant, flexible, and extensible forms library for React Hooks that helps you write less code while achieving better performance. | Provides a `useForm` custom hook as its core API for managing form state, validation, and submission with minimal re-renders. Also offers `useFieldArray` for dynamic forms and `useFormContext` for sharing form methods across nested components, with full TypeScript support throughout. |
| `react-icons` | Include popular icons in your React projects easily, utilizing ES6 imports that allow you to include only the icons that your project is using. | Provides SVG-based React components sourced from popular icon packs such as Font Awesome, Material Design, Bootstrap Icons, and many more — all accessible via simple ES6 named imports. Includes built-in TypeScript type declarations, enabling full type safety and IDE autocompletion. |
| `sonner` | An opinionated toast notification component for React, offering beautiful animations and a clean, accessible design out of the box. | Provides multiple toast types (success, error, warning, info) with support for custom content, actions, and promise-based toasts. Integrates easily into React and TypeScript projects via a simple `<Toaster />` component and a `toast()` function API. |
| `tailwind-merge` | A TypeScript/JavaScript utility for merging Tailwind CSS class names without style conflicts. Intelligently resolves conflicting Tailwind classes, ensuring the last applicable class wins. | The core `twMerge` function accepts multiple class name strings and returns a single, conflict-free merged class string, with built-in LRU caching for performance. Also exposes `extendTailwindMerge` to customize and extend the default merging configuration for projects that modify the standard Tailwind CSS setup. |
| `tailwindcss` | A utility-first CSS framework for rapidly building custom user interfaces and modern websites without ever leaving your HTML. | Provides a comprehensive set of low-level utility classes (e.g., `flex`, `pt-4`, `text-center`, `rotate-90`) that can be composed directly in markup to build any design without writing custom CSS. Supports a highly customizable configuration system, enabling dark mode, responsive breakpoints, extended color palettes, and design tokens. |
| `zod` | A TypeScript-first schema declaration and validation library for defining schemas to validate data — from a simple string to a complex nested object — with static type inference. | Allows developers to declaratively define schemas for primitives, objects, arrays, unions, and more, then parse and validate data against them at runtime with full TypeScript type inference. Widely used for API validation, form validation, and runtime type checking, with zero external dependencies and a concise, chainable API. |
