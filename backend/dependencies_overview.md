# Dependencies Overview

This document is the source-of-truth for all runtime and tooling dependencies of the backend service. Package manager: **uv**. Dependency file: `pyproject.toml`.

## Dependency Catalog

| Package | Version Constraint | Purpose | Usage Notes |
|---|---|---|---|
| alembic | `<2.0.0` | Lightweight database migration tool for SQLAlchemy. Manages versioned, incremental, reversible schema changes. | Write migration scripts in Python; auto-generate migrations by diffing SQLAlchemy models against the live DB. Provides DDL helpers: `alter_column()`, `rename_table()`, `add_constraint()`. |
| email-validator | `<3.0.0.0` | Robust email address syntax and deliverability validation for Python 3.8+. | Primary interface: `validate_email()`. Handles syntax checking, Unicode/internationalized addresses, and normalization (e.g., domain lowercasing). Optionally performs DNS-based deliverability checks. Raises `EmailNotValidError` with detailed messages on failure. |
| emails | `<1.0` | Modern library for building and sending HTML email messages, with attachments and SMTP delivery. | Supports Jinja2 template rendering, inline images, and file attachments. Provides a straightforward SMTP interface with TLS/SSL, authentication, and response handling. |
| fastapi | (unpinned) | Modern, high-performance web framework for building APIs with Python type hints. | Built on Starlette and Pydantic. Delivers automatic interactive API docs (Swagger UI, ReDoc) and data validation/serialization via type annotations. Performance on par with Node.js and Go. |
| httpx | `<1.0.0` | Fully featured HTTP client with sync and async APIs, supporting HTTP/1.1 and HTTP/2. | Familiar `requests`-like API with connection pooling, timeout handling, cookie management, and async support for concurrent HTTP calls. Includes an integrated CLI client. |
| jinja2 | `<4.0.0` | Fast, expressive, extensible templating engine for Python. | Supports template inheritance, inclusion, macro definition/import, filters, tests, and a sandboxed execution environment. Used to render dynamic HTML, config files, or any text-based format. |
| psycopg | (unpinned) | Modern PostgreSQL database adapter implementing Python DB-API 2.0; successor to psycopg2. | Provides both synchronous and asynchronous interfaces. Thread-safe, depends on libpq, and supports advanced PostgreSQL features. Familiar interface for psycopg2 migrants. |
| pwdlib | (unpinned) | Modern password hashing helper; successor to passlib (incompatible with Python 3.13+). | Supports Argon2 and Bcrypt. Provides a `PasswordHash` instance with sensible defaults (Argon2 by default). Simple API to hash and verify passwords; integrates easily with FastAPI. |
| pydantic | (unpinned) | Most widely used data validation library for Python; runtime type checking via type annotations. | Defines data models with standard type hints for automatic validation, parsing, and serialization. Also supports settings management, custom validators, and a rich type system. |
| pydantic-settings | `<3.0.0` | Optional Pydantic extension for loading settings/config from environment variables or secrets files. | Define app config as strongly-typed Pydantic models, auto-populated from env vars, `.env` files, or secrets. Supports type coercion, nested configurations, and customizable sources. |
| pyjwt | `<3.0.0` | Python library to encode and decode JSON Web Tokens (JWT, RFC 7519). | `jwt.encode()` / `jwt.decode()` with HMAC, RSA, and ECDSA algorithms. Validates registered claims (`exp`, `iat`, `aud`). Suitable for authentication and authorization workflows. |
| python-multipart | `<1.0.0` | Streaming multipart/form-data parser for Python; handles file uploads and form submissions. | Streaming parser processes multipart payloads without loading them fully into memory. Used as a dependency by FastAPI/Starlette to parse files and form fields from incoming requests. |
| sentry-sdk | (unpinned) | Official Python SDK for Sentry.io; automatic error and performance reporting. | Initialized via `sentry_sdk.init()`. Captures exceptions and performance metrics. Integrates with FastAPI, Django, Flask, and others. Supports distributed tracing across services. |
| sqlmodel | `<1.0.0` | Library for interacting with SQL databases using Python objects, built on Pydantic and SQLAlchemy. | Define database models as Python classes with full type safety and editor support. Seamless create/query/manage of SQL records using Python object syntax; ideal alongside FastAPI. |
| tenacity | `<9.0.0` | General-purpose retrying library for Python (Apache 2.0); adds resilient retry behavior to any callable. | Decorator-based API with configurable stop conditions (max attempts), wait strategies (exponential backoff), and retry triggers (specific exceptions or return values). Used to handle transient failures in networking and I/O. |
